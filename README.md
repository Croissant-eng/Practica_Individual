# Nombre del proyecto
Catalogo de Recursos

## Descripcion
Un catalogo automatizado en codigo con una app para la flexibilidad y facilidad de uso

## Objetivo
Facilitar al cliente, administrador y empleado la busqueda de recursos disponibles en la empresa
